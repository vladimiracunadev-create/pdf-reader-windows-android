# Manual de usuario

## Abrir un PDF
Pulsa **Abrir PDF** o **Seleccionar PDF** y elige un archivo. En Windows también puedes arrastrarlo sobre la ventana.

## Navegar
Usa `‹` y `›`, escribe una página concreta o abre el panel de miniaturas. En Android puedes deslizar horizontalmente para avanzar o retroceder.

## Zoom
- `−`: alejar.
- `+`: acercar.
- `100%`: escala manual normal.
- **Ancho**: adapta el documento al ancho disponible.
- **Página**: intenta mostrar la página completa.

## Buscar
Pulsa `⌕` o `Ctrl+F`. La búsqueda indica las páginas que contienen la palabra/frase y permite saltar a ellas.

## Rotar y pantalla completa
`↻` rota 90°. `⛶` activa pantalla completa.

## Modo oscuro
El botón `◐` cambia el color de la interfaz. La página PDF mantiene sus colores originales para no alterar visualmente el documento.

## Solo lectura
La app no ofrece Guardar, Editar, Firmar, Anotar ni Eliminar página. El original permanece sin modificaciones.
