# UX y accesibilidad

Principios para usuario novato:
- botones con área táctil mínima cercana a 40–44 px;
- acciones primarias visibles y vocabulario directo;
- controles redundantes en móvil para página/zoom;
- mensajes de error sin jerga técnica;
- foco de teclado visible;
- etiquetas `aria-label` en controles icónicos;
- tema claro/oscuro;
- ayuda rápida integrada;
- no esconder la condición **SOLO LECTURA**.

## Futuras mejoras
- lectura por voz mediante APIs de accesibilidad;
- bookmarks locales;
- miniaturas virtualizadas para documentos de cientos de páginas;
- reflow/text mode para documentos compatibles.
