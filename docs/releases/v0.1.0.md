# PDF Reader v0.1.0

Primera versión pública del lector PDF, con prioridad de validación y distribución en Android.

## Incluye
- lector PDF de solo lectura;
- Windows: instalador NSIS + portable;
- Android 7+: APK release firmado para instalación directa;
- zoom, ajuste, rotación, navegación y miniaturas;
- búsqueda de texto;
- tema oscuro y pantalla completa;
- drag & drop/atajos en Windows y swipe en Android;
- GitHub Pages como demo web;
- CI completo de Web + Windows + Android.
- verificación de firma, paquete, versión, permisos y contenido del APK;
- checksums SHA-256 de todos los binarios.

## Nota
El ejecutable Windows no está firmado con Authenticode en esta fase. El APK Android sí está firmado con una clave persistente de distribución directa, pero todavía no es una entrega de Google Play.
