# PDF Reader v0.3.3

Release de consolidación de las mejoras móviles y del gate integral de calidad. Esta versión incorpora en los artefactos descargables las correcciones, pruebas reproducibles y documentación que se ampliaron después de v0.3.2.

## Correcciones incluidas

- Android mantiene visible la página al encadenar navegación, zoom, ajuste y rotación mediante render de doble búfer.
- Android 16 respeta barras del sistema y recortes de pantalla con insets nativos.
- Los controles táctiles principales alcanzan al menos 44×44 CSS px.
- Compartir en Windows copia un resumen local acotado, confirma la acción y nunca adjunta el PDF.
- El renderer declara Content Security Policy y limita los enlaces externos permitidos.
- Los harnesses Web y Android parten de estado limpio y reproducen selección de documentos, acciones compuestas, lifecycle y recuperación.

## Validación requerida

- 29/29 pruebas Node y gate estructural/documental.
- 47/47 casos E2E en Electron real.
- 21/21 casos Web localhost en Edge/Chromium a 390×844.
- 21/21 casos sobre APK debug instalada en Android Emulator API 36.1.
- Corpus de 16 clases PDF mediante selector real de archivos: una página, multipágina, 1.000 páginas, Word, navegador, escaneado, imágenes, texto, mixto, tamaños/orientaciones, 96 MiB, alta resolución, metadatos/enlaces, fuentes embebidas, páginas rotadas y entradas negativas seguras.
- Acciones compuestas página → zoom → rotación, pinza, doble toque, swipe, orientación, background/foreground, historial y recuperación.

La evidencia definitiva de CI, descarga, hashes, instalación limpia y repetición sobre los binarios publicados se completa en [el informe de release](https://github.com/vladimiracunadev-create/pdf-reader-windows-android/blob/main/reports/release-evidence-v0.3.3.md). La matriz completa está en [la validación PDF](https://github.com/vladimiracunadev-create/pdf-reader-windows-android/blob/main/reports/pdf-functional-validation-2026-09-28.md).

## Límites explícitos

- Teléfono Android físico: **NO EJECUTADO**. El emulador no se presenta como sustituto de hardware físico.
- Fallback Web de compartir hacia un servicio externo: **NO EJECUTADO**, porque requiere salida de datos fuera del entorno de prueba.
- Windows no incluye firma Authenticode.
- La suite UI completa se ejecuta localmente; CI valida pruebas Node, builds Android/Windows, empaquetado y contrato del release.
