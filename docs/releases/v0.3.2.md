# PDF Reader v0.3.2

Release de corrección y verificación integral. El cierre exige código integrado, pruebas sobre aplicaciones en ejecución, documentación y repetición sobre los artefactos publicados.

## Correcciones

- Android conserva la página visible mientras prepara zoom, navegación o rotación; un doble búfer evita el parpadeo que parecía una recarga.
- Android 16 aplica insets nativos al WebView: cabecera, controles y navegación dejan de quedar bajo las barras del sistema.
- Los controles táctiles principales cumplen un mínimo observable de 44×44 CSS px.
- Compartir en Windows copia un resumen acotado al portapapeles mediante IPC, muestra confirmación y no transmite ni adjunta el PDF.
- El renderer declara una Content Security Policy local. Los enlaces externos de About quedan limitados al repositorio y sus releases.

## Validación previa al release

- 29/29 pruebas Node.
- 47 casos E2E en Electron real.
- 14 casos E2E en la APK Android instalada: navegación, salto, zoom, miniaturas, búsqueda, tema, swipe, pinza, secuencia rápida, paneles, orientación, background/foreground, áreas seguras y objetivos táctiles.
- Corpus de 16 clases PDF, incluido Word, navegador, escaneado, imágenes, 1.000 páginas, 96 MiB, alta resolución, fuentes, metadatos/enlaces, rotaciones, contraseña y corrupción recuperable.
- Android físico sigue como **NO EJECUTADO**; el emulador API 36.1 no se presenta como sustituto.

## Validación posterior ampliada

Después de publicar los binarios, se amplió y repitió la verificación sobre el mismo código de producto:

- 21/21 casos Web localhost en Edge/Chromium a 390×844;
- 21/21 casos sobre la APK debug instalada en Android Emulator API 36.1;
- las 16 variantes PDF abiertas mediante DocumentsUI en Android;
- acciones compuestas página → zoom → rotación sin desaparición del canvas;
- pinza, doble toque, swipe, orientación, background/foreground, historial y recuperación;
- Setup descargado desde este release, instalado de forma aislada y ejecutado con 47/47 E2E;
- CI de integración [`36504652217`](https://github.com/vladimiracunadev-create/pdf-reader-windows-android/actions/runs/36504652217) y Pages [`36504652223`](https://github.com/vladimiracunadev-create/pdf-reader-windows-android/actions/runs/36504652223), ambos PASS.

Esta ampliación incorpora pruebas y documentación; no cambia los binarios ya publicados de `v0.3.2`. La prueba en teléfono Android físico y el fallback Web de compartir hacia un servicio externo permanecen **NO EJECUTADOS**.

Consulta [la matriz auditable](https://github.com/vladimiracunadev-create/pdf-reader-windows-android/blob/main/reports/pdf-functional-validation-2026-09-28.md) y [la evidencia del release](https://github.com/vladimiracunadev-create/pdf-reader-windows-android/blob/main/reports/release-evidence-v0.3.2.md).
