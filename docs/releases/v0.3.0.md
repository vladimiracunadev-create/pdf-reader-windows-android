# PDF Reader v0.3.0

Release Android-first centrado en que ampliar un documento sea predecible y nunca oculte contenido.

## Corrección principal

- El lienzo ampliado crece con el PDF en lugar de desbordarse hacia coordenadas negativas.
- Los bordes izquierdo y derecho siguen siendo alcanzables mediante desplazamiento horizontal, también en pantallas de 320 px.
- Los botones de zoom, la pinza y el doble toque conservan el punto de lectura bajo el centro del visor o del gesto.
- La rotación y los modos **Ancho**/**Página** mantienen una referencia estable.
- La primera ampliación con desbordamiento explica brevemente que se puede deslizar para recorrer toda la página.

## Experiencia y compatibilidad

- Android sigue siendo la prioridad: Android 7.0+ (API 24), `versionCode` 3.
- Conserva historial local reabrible, tema claro/oscuro, About, compartir mediante la hoja nativa y la pregunta opcional para elegir PDF Reader como lector predeterminado.
- Continúa sin cuentas, backend, telemetría, permiso de Internet ni acceso general al almacenamiento.
- Windows 10/11 y GitHub Pages usan el mismo núcleo de lectura.

## Verificación

- 9 pruebas unitarias, incluida la geometría del ancla de lectura.
- Guardia de repositorio contra la regresión del layout que recortaba el borde izquierdo.
- Prueba visual y geométrica con PDF real a 390×844 y 320×700: ambos bordes alcanzables y ajuste al ancho sin overflow.
- CI compila y prueba Web, Android y Windows.
- El workflow del tag genera APK firmado, instalador y portable de Windows, además de `SHA256SUMS.txt`.

## Actualización Android

Instala `PDF-Reader-Android-v0.3.0.apk` sobre una versión anterior. El package name y el certificado se conservan; `versionCode` aumenta de 2 a 3.

Consulta el [manual de usuario](../user-guide.md) y la [guía Android](../android.md).
