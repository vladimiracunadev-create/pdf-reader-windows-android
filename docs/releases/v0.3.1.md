# PDF Reader v0.3.1

Release correctivo centrado en que revisar un PDF sea determinista tanto en documentos breves como en documentos de cientos o miles de páginas.

## Navegación corregida

- Un swipe sobre una página ampliada solo cambia de página si el gesto **comienza** en el borde correspondiente. Llegar al borde durante el mismo arrastre ya no avanza accidentalmente.
- Escribir un número y pulsar **Enter** sincroniza el campo, la página renderizada y la navegación siguiente.
- Repetir una acción sobre la primera o última página no vuelve a renderizar innecesariamente la misma página.
- Abrir otro documento cierra paneles y cancela trabajos del PDF anterior.

## Documentos grandes

- La apertura inicial ya no construye miniaturas que la persona no solicitó.
- El panel carga ventanas navegables de 60 páginas, manteniendo acceso a todo el documento mediante lotes anterior/siguiente y salto directo.
- Cerrar el panel detiene la generación pendiente; cerrar una búsqueda larga también cancela el recorrido y muestra un estado explícito.
- El generador sintético permite reproducir pruebas con documentos de 1 a 2.000 páginas sin datos privados.

## Evidencia funcional

Se ejecutaron recorridos reales en Chromium local con PDF sintéticos de 1, 12 y 1.000 páginas:

- límites anterior/siguiente;
- salto directo, Enter, flechas, Home y End;
- zoom, ajuste, rotación y controles móviles a 390 × 844;
- miniaturas por lotes, búsqueda, cancelación, historial y reapertura;
- recuperación ante un PDF inválido sin cerrar el documento vigente.

La matriz observable está en [`reports/functional-reading-validation-2026-09-24.md`](../../reports/functional-reading-validation-2026-09-24.md). Las 24 pruebas Node y el gate `release:check` pasan antes del tag.

## Plataformas y privacidad

- Android 7.0+ (API 24), `versionCode` 4.
- Windows 10/11 y GitHub Pages usan el mismo núcleo de lectura.
- Sin cuenta, backend, telemetría, permiso de Internet ni acceso general al almacenamiento.
- El APK release mantiene el package `cl.vladimiracunadev.pdfreader` y el certificado de las versiones anteriores para permitir actualización directa.

## Actualización

En Android, instala `PDF-Reader-Android-v0.3.1.apk` sobre la versión anterior. En Windows, usa el instalador o portable `0.3.1`. Verifica los archivos con `SHA256SUMS.txt` publicado en este release.

Persisten límites conocidos: no hay diálogo para PDF con contraseña, OCR, firma/edición, Play Store ni firma Authenticode para Windows. Las pruebas físicas de swipe, pinza, rotación del sistema y compartir nativo siguen siendo un gate separado; no se infieren desde el build.
